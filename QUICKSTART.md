# Quick Start Guide

Get up and running with Facebook Marketplace Watcher in 5 minutes!

## 1. Build the Extension (2 minutes)

```bash
git clone https://github.com/Andrew53O/fb-watcher.git
cd fb-watcher
npm install
npm run build
```

## 2. Install in Chrome (1 minute)

1. Open Chrome and go to `chrome://extensions/`
2. Toggle **Developer mode** ON (top-right)
3. Click **Load unpacked**
4. Select the `dist` folder

## 3. Configure (2 minutes)

1. Click the extension icon
2. Go to **Settings** tab
3. Add keywords (e.g., `laptop`, `bike`, `furniture`)
4. Set price range (e.g., `0` to `1000`)
5. Click **Save Settings**

## 4. Start Watching!

1. Open [Facebook Marketplace](https://www.facebook.com/marketplace)
2. The extension will automatically scan every 30 minutes
3. Get notifications for matching posts!
